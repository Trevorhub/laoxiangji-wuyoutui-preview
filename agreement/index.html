老乡鸡付费会员服务协议

生效日期：2026年9月4日

欢迎您使用老乡鸡付费会员服务！

《老乡鸡付费会员服务协议》（以下简称“本协议”）是您与购买页面所示的老乡鸡付费会员服务提供方（以下简称“我们”）之间，就您购买、使用老乡鸡付费会员权益及相关服务订立的协议。请您在购买前仔细阅读本协议，特别是以加粗等显著方式提示的内容。您勾选同意或完成购买，即表示您已阅读、理解并同意本协议。

我们将按照《老乡鸡隐私政策》及相关个人信息处理规则，依法处理为开通、使用、结算及保障会员服务所必要的个人信息；如相关处理需要另行取得您的同意，我们将依法单独征得同意。

未成年人应在法定监护人陪同和指导下阅读并使用本服务。

一、定义与规则关系

  1. 老乡鸡付费会员权益：指老乡鸡官方平台提供的各类付费会员产品及其对应权益。不同产品的权益内容、价格、有效期及适用范围可能不同，以您购买时确认的信息为准。
  2. 老乡鸡付费会员：指成功购买或依法取得老乡鸡付费会员权益，并在有效期内使用相关服务的自然人。
  3. 老乡鸡付费会员服务：指老乡鸡依据本协议及具体产品规则向付费会员提供的服务。
  4. 期限单位：除具体产品规则另有明确约定外，本协议及购买页面所称“月”按 30 个自然日计算，“季”按 90 个自然日计算，“年”按 365 个自然日计算；具体有效期起止时间以订单及会员页面记录为准。
  5. 具体产品规则：指针对超级会员等特定付费会员产品制定并在购买时向您展示的购买须知、权益详情、活动规则及本次交易页面信息。具体产品规则是本协议的组成部分。
  6. 规则适用：本协议为通用规则；具体产品规则对权益内容、适用范围、有效期、自动续费或退款等有特别约定的，适用特别约定。本次购买页面中经您确认的卡种、成交价格、明确起止时间、权益适用范围及适用资格属于具体交易信息。任何事后调整不得追溯减少您已开始付费周期内的权益，法律另有规定的除外。

二、购买、支付、有效期与自动续费

  1. 购买渠道：您可通过老乡鸡官方小程序或其他明确标示的官方渠道购买付费会员产品。实际可购产品及支付方式以购买页面为准。
  2. 交易信息：产品名称、权益内容、价格、优惠、有效期及适用范围以您付款前确认的购买页面为准。请在付款前核对会员账号及相关交易信息。
  3. 开通及有效期：通常自支付成功并开通之时起计算，具体起止时间以订单及会员页面记录为准。购买页面用于付款前确认，支付签约记录用于确认自动续费授权、扣费周期及支付信息。因系统异常导致支付成功但未开通的，您可联系客服核查处理。
  4. 自动续费：自动续费须由您主动选择开通。我们将在您接受服务前以及每次自动续费日前，以显著方式提示续费产品、本次扣费时间和金额及取消路径。您可在服务期间通过购买页面提示的支付渠道管理入口随时关闭自动续费，且不收取不合理费用。关闭自动续费仅影响下一付费周期，不会立即终止当前会员资格，也不等同于主动退卡。
  5. 续费及扣费失败：续费价格以续费前向您公示并提示的价格为准。因账户余额不足、账户状态异常或支付渠道故障导致扣费失败的，我们可在支付授权及已提示的扣费安排范围内再次尝试扣费或提示您手动续费，不会对同一付费周期重复扣款；超出该范围的，将重新提示并依法取得相应授权。未成功续费的，会员资格在当前有效期届满后终止。
  6. 价格调整：我们可根据经营情况依法调整后续购买或续费价格，并在生效前公示或通知。调整不影响您已支付并开始的付费周期。

三、会员权益与使用

  1. 权益内容：不同付费会员产品的折扣、会员券、限时活动及其他权益可能不同，以对应产品规则和购买时页面展示为准。
  2. 使用范围：权益适用渠道、门店、时段、商品、次数、优惠上限及是否可叠加，以具体产品规则或权益详情为准。医院、机场、火车站、旅游景区等特殊场景门店及部分商品不参与。
  3. 账号与本人使用：除具体产品规则另有明确约定外，付费会员权益仅限会员本人、非商业性使用。您应妥善保管账号、密码及会员凭证，不得通过共享账号、截图、转让或出租等方式授权他人使用。
  4. 禁止不当使用：不得利用会员权益进行套现、转售、批量套利或其他违法、违约活动。发现异常时，我们可采取核验、临时限制相关权益等与风险程度相适应的必要措施，并向您说明理由及提供申诉渠道；核验后应及时解除不再必要的限制。因误限影响您使用的，我们将根据实际影响依法延期、补发或提供相应补救。您可通过客服申请核查并补充证据。
  5. 权益调整：因商品上下架、门店供应或合理经营安排，需要调整尚未开始的后续权益时，我们将依法公示或通知；已经开始的付费周期原则上不受影响。因客观原因确需调整当前周期核心权益的，我们将征得您的同意，或由您选择合理替代方案、按受影响程度退还相应费用等处理方式。

四、关闭续费、终止与退款

  1. 一般退款原则：付费会员服务属于数字化会员服务。除法律法规规定、因我们原因未按约提供服务、发生重复扣款或开通失败、购买页面作出特别退款承诺，或具体产品规则另有约定外，会员服务成功开通后，不因您单方关闭自动续费而退还当前周期费用。
  2. 关闭自动续费：关闭自动续费仅停止下一周期扣费，当前会员资格及当前周期内已取得权益按原有效期继续有效。
  3. 主动终止会员：主动终止会员与关闭自动续费的含义及影响不同。如具体产品提供“退卡”或提前终止入口，其生效时点、当期费用及已领取权益的处理，以您操作前页面显著展示并确认的产品规则为准，请根据页面提示分别操作。
  4. 特别退款承诺：购买页面明确作出特别退款承诺的，按照您购买时已显著展示并确认的具体产品规则执行；我们不会在购买后新增减损您权益的退款条件。

五、服务中断、第三方渠道与责任

  1. 因系统维护、网络或设备故障、公共卫生事件、政府行为及其他无法合理控制的客观原因影响服务时，我们将采取合理措施减少影响、尽快恢复，并根据实际影响依法承担责任。
  2. 因支付机构、网络运营商等第三方原因导致扣费、退款或到账延迟的，我们将协助查询和处理；第三方原因不当然免除我们依法或依约应承担的责任。
  3. 因您操作不当、账号状态异常或未按页面提示使用服务造成的损失，由责任方依法承担；我们将提供合理的查询和协助。

六、法律适用与争议处理

  1. 本协议适用中华人民共和国法律。任何条款被认定无效或不可执行的，不影响其他条款的效力。
  2. 您对订单、会员权益或退款判定有异议的，可先通过客服渠道申请核查。协商不成的，任一方可依法向有管辖权的人民法院提起诉讼。

七、协议修订、通知与联系

  1. 我们可能依法修订本协议。涉及价格、自动续费、退款、责任承担等与您有重大利害关系的变化，将在生效前以显著方式通知。修订不追溯减少您已开始付费周期内的权益。
  2. 如您不同意影响后续周期的修订，可在下一周期扣费前关闭自动续费；当前已支付周期仍按购买时适用规则执行，法律另有规定或双方另有协商的除外。
  3. 我们将按照适用法律法规保存协议版本及相关交易记录。如您对适用于已购会员服务的协议版本有疑问，可通过本协议载明的客服渠道咨询。
  4. 如有疑问，可联系老乡鸡客服热线 400-766-1777 或通过小程序在线客服咨询。
